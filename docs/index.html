Which species and strains convert a substrate to a product, and by what pathway?

Mode 1 ranks enzyme-presence pathways; Mode 2 tests flux feasibility for a chosen GEM on an editable medium, solved in the browser.

      • Currency metabolites (ATP, NAD, water…) are never used as pathway intermediates.
